# Da Linguagem Humana ao Computador

Página educacional interativa que mostra a relação entre:

- caractere humano;
- código ASCII;
- decimal;
- binário;
- octal;
- hexadecimal;
- Unicode.

## Como executar

Abra o arquivo `index.html` diretamente no navegador.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub.
2. Envie o arquivo `index.html`.
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve e aguarde o endereço público ser gerado.

## Controles

- `CONTAR +1`: avança na tabela ASCII.
- `−1`: volta um código.
- `Zerar`: retorna ao código 0.
- Setas do teclado: avançar ou voltar.
- Espaço: avançar.
- `R`: zerar.
- Campo de texto: converte um caractere ASCII digitado.
