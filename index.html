ASCII de 0 a 127

Dec Hex Binário Caractere

ASCII clássico usa 7 bits e possui 128 códigos, de 0 a 127. Nesta página, cada código é exibido dentro de um byte de 8 bits, por isso há um zero inicial.

Projeto educacional: uma mesma sequência de bits pode receber diferentes interpretações.
